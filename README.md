# MyFamily

Eine WebApp zur Verwaltung persönlicher Gegenstände aller Familienmitglieder
in verschiedenen Kategorien (z.B. Modelleisenbahn, Schmuck, Boots-Inventar),
inklusive Auswertungen für die Hausratsversicherung.

## Erste Schritte

Im Projektordner ausführen:

```
npm install
npm run dev
```

Danach ist die App unter http://localhost:3000 erreichbar.

## Tech-Stack

- Next.js (App Router, TypeScript)
- Tailwind CSS
- Prisma + SQLite (folgt im nächsten Schritt)
- Auth.js für Mehrbenutzer-Login (folgt)
